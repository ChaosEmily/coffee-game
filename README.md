# 遊戲系統企劃書：高章洙的咖啡危機 (Coffee Baum 758)

## 1. 專案概述
*   **遊戲名稱**：高章洙的咖啡危機 (Coffee Baum 758)
*   **遊戲類型**：經營模擬決策 (Management Simulation)
*   **遊戲核心**：玩家扮演經營顧問，在南韓咖啡市場極度飽和的背景下，協助店主高章洙在四個季度中做出正確決策以生存。
*   **敘事目標**：透過真實數據（紐約時報資料）反映咖啡店經營的現實困境。

---

## 2. 核心遊戲循環 (Core Game Loop)
1.  **季度開場**：顯示季度敘事文案（環境背景介紹）。
2.  **事件觸發**：50% 機率發生隨機市場事件，影響當季評分標準。
3.  **決策階段**：玩家需在「裝潢、菜單、品管」三個維度中各選一項策略。
4.  **季度結算**：計算總分，判斷當季盈虧，並顯示基於真實產業現狀的深度回饋。
5.  **終局判定**：四個季度結束後，依據累計積分決定最終結局。

---

## 3. 數值與計分系統 (Scoring System)

### 3.1 基礎決策權重 (Base Matrix)
每個選項的原始分值代表該策略與該季節需求的「契合度」（3: 優、1: 平、-1: 劣）。

| 季度 | 決策類別 | 選項 A | 選項 B | 選項 C | 企劃設計邏輯 |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **春季** | 裝潢/菜單/品管 | 3 / 3 / 1 | 1 / 1 / -1 | -1 / -1 / 3 | 重視視覺吸引力與精品化初衷。 |
| **夏季** | 裝潢/菜單/品管 | 1 / 3 / 3 | 3 / 1 / 1 | -1 / -1 / -1 | 重視效率、產量與勞動條件改善。 |
| **秋季** | 裝潢/菜單/品管 | -1 / 1 / 3 | 3 / 1 / 1 | 1 / 3 / -1 | 重視社群行銷與在地文化差異化。 |
| **冬季** | 裝潢/菜單/品管 | 1 / 3 / 3 | -1 / 1 / 1 | 3 / -1 / -1 | 重視顧客忠誠度與高 CP 值組合。 |

### 3.2 隨機事件修正 (Event Modifiers)
事件會動態調整特定選項的權重（$\Delta$ 值），模擬市場波動。

*   **範例事件：咖啡豆價格飆升 (春季)**
    *   品管-C (精品豆) $\rightarrow$ **+2** (應對成本衝擊效益高)
    *   菜單-B (傳統咖啡) $\rightarrow$ **-2** (利潤空間被壓縮)
*   **範例事件：網紅探店衝擊 (秋季)**
    *   裝潢-A (拍照風格) $\rightarrow$ **+2** (流量轉換率提升)
    *   品管-A (KOL 合作) $\rightarrow$ **-2** (邊際效益遞減)

---

## 4. 判定與反饋邏輯

### 4.1 季度盈虧判定
*   **成功門檻**：$RoundScore \ge 7$ 分。
*   **成功回饋**：顯示積極對話，強調顧客回流。
*   **失敗回饋**：顯示消極對話，強調現金流壓力與退場念頭。

### 4.2 內容回饋演算法 (Dynamic Feedback)
系統會識別該回合玩家**得分最高**的維度，並根據「成功/失敗」狀態，抓取對應的 **【數據資料】** 或 **【調查資料】**（引用自紐約時報真實報導），加深遊戲的現實沉浸感。

---

## 5. 結局分支設計 (Ending Branching)

根據玩家全場累計積分 ($S$) 決定最終敘事結局：

| 結局類型 | 觸發條件 | 劇情走向 | 象徵意義 |
| :--- | :--- | :--- | :--- |
| **結局 1：絕望的退出者** | $S \le 4$ | 高章洙關閉店面，深感後悔。 | 反映高達 60% 的新店兩年內倒閉現狀。 |
| **結局 2：苦撐的生存者** | $5 \le S \le 18$ | 勉強維持，但每日工時極長且利潤微薄。 | 反映南韓咖啡主業者的普遍現狀。 |
| **結局 3：成功的弄潮兒** | $S > 18$ | 成為網美名店，成功轉型。 | 極少數成功突圍的經營典範。 |

---

## 6. UI/UX 流程需求 (UI Interaction)

### 6.1 視覺動態要求
*   **狀態回饋**：隨機事件發生時畫面應有警示感 (`pulse`)。

### 6.2 操作限制
*   **防呆機制**：必須在三個維度（裝潢、菜單、品管）各完成一次點選後，系統才允許點擊「提交建議」。
*   **流程流暢度**：回合結算後，需顯示詳細的分數來源清單 (Breakdown)，確保玩家了解決策影響。

---

## 7. 企劃備註
*   **平衡性建議**：若測試發現遊戲難度過高，可調降季度成功門檻（如從 7 分降至 5 分）。
